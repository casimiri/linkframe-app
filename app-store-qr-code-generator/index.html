App download QR code generator

An app download QR code is a single code for every phone: iPhones are sent to your App Store page, Android phones to Google Play, and computers or other devices to your website. You print one code instead of two and nobody lands on the wrong store.

Because it routes each scan by device, this is a smart (dynamic) code that needs a free account, which can keep up to 2 saved codes with scan statistics. The generator below makes a free static link code without signing up.

How to create it

  1. Create a free account and choose “Smart app link” as the destination.
  2. Paste your App Store link, your Google Play link and a fallback web page.
  3. Style the code and add your app icon as the logo.
  4. Download it and track scans by device in your dashboard.

Frequently asked questions

Why do I need an account?

The device routing happens on our server each time the code is scanned, so the code has to be saved to an account. Accounts are free and can keep up to 2 saved codes.

Can I add a logo and my own colours?

Yes. Upload a PNG, JPG, WebP or SVG logo, pick colours or a gradient, and choose dot, corner and frame styles. The logo is embedded in your browser and never leaves your device.

Should I download PNG or SVG for print?

Use SVG for print: it is a vector file that stays sharp at any size, from business cards to posters. PNG (1024 px) is best for websites, documents and social media.

Can I change the store links later?

Yes. Smart codes are dynamic, so you can edit the destinations from your dashboard at any time without reprinting the code.
