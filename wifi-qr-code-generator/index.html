Wi-Fi QR code generator

A Wi-Fi QR code connects a phone to your network in one scan, with no password to spell out. Put it on a table card in your café, in a holiday rental, in a meeting room or on the fridge for visiting friends.

Enter the network name (SSID) exactly as it appears, choose the security type and type the password. Most routers use WPA/WPA2/WPA3; pick “None (open)” only for networks without a password.

How to create it

  1. Enter the network name and password.
  2. Choose the security type and tick “hidden” if the network is not broadcast.
  3. Style the code and add a frame such as “Scan for Wi-Fi”.
  4. Download, print and place it where guests can see it.

Frequently asked questions

Is it free, and do the codes expire?

Yes, it is free and there is nothing to sign up for. The codes made here are static: the content is stored inside the pattern itself, so they keep working forever and never depend on our servers.

Can I add a logo and my own colours?

Yes. Upload a PNG, JPG, WebP or SVG logo, pick colours or a gradient, and choose dot, corner and frame styles. The logo is embedded in your browser and never leaves your device.

Should I download PNG or SVG for print?

Use SVG for print: it is a vector file that stays sharp at any size, from business cards to posters. PNG (1024 px) is best for websites, documents and social media.

Is my Wi-Fi password sent to your servers?

No. The code is generated in your browser; nothing is uploaded. The password is stored only inside the QR pattern you download.
