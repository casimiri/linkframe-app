Générateur de QR code vCard

Un QR code vCard contient une fiche contact complète : nom, téléphone, e-mail, société, fonction et site web. Au scan, le téléphone propose de l’enregistrer dans le carnet d’adresses, sans recopier votre carte de visite à la main.

Imprimez-le sur vos cartes de visite, badges, stands de salon ou dans votre signature e-mail. Ne remplissez que les champs utiles : moins de champs donnent un code plus léger, plus facile à scanner.

Comment le créer

  1. Renseignez votre nom et les coordonnées à partager.
  2. Personnalisez les couleurs et ajoutez votre logo.
  3. Scannez l’aperçu pour vérifier la fiche contact.
  4. Téléchargez en SVG pour l’impression ou en PNG pour le numérique.

Questions fréquentes

Est-ce gratuit ? Les codes expirent-ils ?

Oui, c’est gratuit et sans inscription. Les codes créés ici sont statiques : le contenu est inscrit dans le motif lui-même, ils fonctionnent donc pour toujours, sans dépendre de nos serveurs.

Puis-je ajouter un logo et mes couleurs ?

Oui. Importez un logo PNG, JPG, WebP ou SVG, choisissez vos couleurs ou un dégradé, ainsi que le style des points, des coins et du cadre. Le logo est intégré dans votre navigateur et ne quitte jamais votre appareil.

PNG ou SVG pour l’impression ?

Pour l’impression, prenez le SVG : c’est un fichier vectoriel qui reste net à toutes les tailles, de la carte de visite à l’affiche. Le PNG (1024 px) convient aux sites web, documents et réseaux sociaux.

Puis-je modifier mes coordonnées après impression ?

Pas avec une vCard statique, car les informations sont dans le code. Si elles changent souvent, créez un compte gratuit et utilisez un code dynamique pointant vers une page modifiable.
