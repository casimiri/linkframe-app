Générateur de QR code gratuit

QR TekLid transforme un lien, un réseau Wi-Fi, une carte de visite, un e-mail, un numéro de téléphone ou un SMS en QR code en quelques secondes. Il suffit de le scanner avec l’appareil photo d’un smartphone pour accéder au contenu, sans installer d’application.

Tout se passe dans votre navigateur : saisissez le contenu, personnalisez le code avec vos couleurs, un cadre et votre logo, puis téléchargez-le en PNG ou en SVG. Pas d’inscription, pas de filigrane et aucune date d’expiration pour les codes créés ici.

Comment le créer

  1. Choisissez le contenu du code : lien, texte, Wi-Fi, contact, etc.
  2. Saisissez les informations ; l’aperçu se met à jour en direct.
  3. Si vous le souhaitez, choisissez couleurs, cadre, style des points et ajoutez votre logo.
  4. Téléchargez le code en PNG pour l’écran ou en SVG pour l’impression.

Questions fréquentes

Est-ce gratuit ? Les codes expirent-ils ?

Oui, c’est gratuit et sans inscription. Les codes créés ici sont statiques : le contenu est inscrit dans le motif lui-même, ils fonctionnent donc pour toujours, sans dépendre de nos serveurs.

Puis-je ajouter un logo et mes couleurs ?

Oui. Importez un logo PNG, JPG, WebP ou SVG, choisissez vos couleurs ou un dégradé, ainsi que le style des points, des coins et du cadre. Le logo est intégré dans votre navigateur et ne quitte jamais votre appareil.

PNG ou SVG pour l’impression ?

Pour l’impression, prenez le SVG : c’est un fichier vectoriel qui reste net à toutes les tailles, de la carte de visite à l’affiche. Le PNG (1024 px) convient aux sites web, documents et réseaux sociaux.

Puis-je changer la destination d’un code déjà imprimé ?

Pas avec un code statique. Il faut pour cela un code dynamique, disponible avec un compte gratuit (jusqu’à 2 codes enregistrés), modifiable à tout moment et accompagné de statistiques de scans.
