Générateur de QR code Wi-Fi

Un QR code Wi-Fi connecte un téléphone à votre réseau en un scan, sans épeler le mot de passe. Posez-le sur les tables de votre café, dans une location de vacances, une salle de réunion ou sur le frigo pour vos amis de passage.

Saisissez le nom du réseau (SSID) exactement tel qu’il apparaît, choisissez le type de sécurité et tapez le mot de passe. La plupart des box utilisent WPA/WPA2/WPA3 ; choisissez « Aucune (ouvert) » uniquement pour un réseau sans mot de passe.

Comment le créer

  1. Saisissez le nom du réseau et le mot de passe.
  2. Choisissez le type de sécurité et cochez « Réseau masqué » si le réseau n’est pas diffusé.
  3. Personnalisez le code et ajoutez un cadre comme « Scannez pour le Wi-Fi ».
  4. Téléchargez, imprimez et placez-le bien en vue.

Questions fréquentes

Est-ce gratuit ? Les codes expirent-ils ?

Oui, c’est gratuit et sans inscription. Les codes créés ici sont statiques : le contenu est inscrit dans le motif lui-même, ils fonctionnent donc pour toujours, sans dépendre de nos serveurs.

Puis-je ajouter un logo et mes couleurs ?

Oui. Importez un logo PNG, JPG, WebP ou SVG, choisissez vos couleurs ou un dégradé, ainsi que le style des points, des coins et du cadre. Le logo est intégré dans votre navigateur et ne quitte jamais votre appareil.

PNG ou SVG pour l’impression ?

Pour l’impression, prenez le SVG : c’est un fichier vectoriel qui reste net à toutes les tailles, de la carte de visite à l’affiche. Le PNG (1024 px) convient aux sites web, documents et réseaux sociaux.

Mon mot de passe Wi-Fi est-il envoyé à vos serveurs ?

Non. Le code est généré dans votre navigateur ; rien n’est envoyé. Le mot de passe n’existe que dans le QR code que vous téléchargez.
