Générateur de QR code de téléchargement d’app

Un QR code de téléchargement d’app est un code unique pour tous les téléphones : les iPhone arrivent sur votre page App Store, les Android sur Google Play, et les ordinateurs ou autres appareils sur votre site. Un seul code à imprimer, et personne ne se trompe de store.

Comme il oriente chaque scan selon l’appareil, c’est un code intelligent (dynamique) qui nécessite un compte gratuit, pouvant conserver jusqu’à 2 codes avec statistiques. Le générateur ci-dessous crée un code lien statique gratuit, sans inscription.

Comment le créer

  1. Créez un compte gratuit et choisissez « Lien app intelligent » comme destination.
  2. Collez votre lien App Store, votre lien Google Play et une page web de secours.
  3. Personnalisez le code et ajoutez l’icône de votre app comme logo.
  4. Téléchargez-le et suivez les scans par appareil dans votre tableau de bord.

Questions fréquentes

Pourquoi faut-il un compte ?

L’orientation par appareil se fait sur notre serveur à chaque scan : le code doit donc être enregistré dans un compte. Les comptes sont gratuits et peuvent conserver jusqu’à 2 codes.

Puis-je ajouter un logo et mes couleurs ?

Oui. Importez un logo PNG, JPG, WebP ou SVG, choisissez vos couleurs ou un dégradé, ainsi que le style des points, des coins et du cadre. Le logo est intégré dans votre navigateur et ne quitte jamais votre appareil.

PNG ou SVG pour l’impression ?

Pour l’impression, prenez le SVG : c’est un fichier vectoriel qui reste net à toutes les tailles, de la carte de visite à l’affiche. Le PNG (1024 px) convient aux sites web, documents et réseaux sociaux.

Puis-je changer les liens des stores plus tard ?

Oui. Les codes intelligents sont dynamiques : modifiez les destinations depuis votre tableau de bord à tout moment, sans réimprimer le code.
