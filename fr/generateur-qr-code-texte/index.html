Générateur de QR code texte

Un QR code texte stocke un message directement dans le motif. Au scan, le téléphone affiche simplement le texte, sans connexion internet. Pratique pour des consignes, des numéros de série, de courtes notes, une chasse au trésor ou l’étiquetage de matériel.

Comme le texte est dans le code, plus il est long, plus le motif est dense. Limitez-vous à quelques phrases pour une lecture fiable, et imprimez le code en plus grand si le message est long.

Comment le créer

  1. Saisissez ou collez votre message.
  2. Personnalisez le code : couleurs, cadre ou logo.
  3. Scannez l’aperçu pour vérifier que le texte s’affiche bien.
  4. Téléchargez en PNG ou en SVG.

Questions fréquentes

Est-ce gratuit ? Les codes expirent-ils ?

Oui, c’est gratuit et sans inscription. Les codes créés ici sont statiques : le contenu est inscrit dans le motif lui-même, ils fonctionnent donc pour toujours, sans dépendre de nos serveurs.

Puis-je ajouter un logo et mes couleurs ?

Oui. Importez un logo PNG, JPG, WebP ou SVG, choisissez vos couleurs ou un dégradé, ainsi que le style des points, des coins et du cadre. Le logo est intégré dans votre navigateur et ne quitte jamais votre appareil.

PNG ou SVG pour l’impression ?

Pour l’impression, prenez le SVG : c’est un fichier vectoriel qui reste net à toutes les tailles, de la carte de visite à l’affiche. Le PNG (1024 px) convient aux sites web, documents et réseaux sociaux.

Combien de texte un QR code peut-il contenir ?

En théorie quelques milliers de caractères, mais un long texte produit un code très dense, difficile à scanner. Pour de bons résultats, restez sous 300 caractères environ.
