vCard-QR-Code-Generator

Ein vCard-QR-Code enthält eine vollständige Kontaktkarte: Name, Telefon, E-Mail, Firma, Position und Website. Beim Scannen bietet das Handy an, den Kontakt zu speichern – niemand muss Ihre Visitenkarte abtippen.

Drucken Sie ihn auf Visitenkarten, Namensschilder, Messestände oder fügen Sie ihn in Ihre E-Mail-Signatur ein. Füllen Sie nur die nötigen Felder aus: Weniger Felder ergeben einen schlankeren Code, der sich leichter scannen lässt.

So erstellen Sie ihn

  1. Tragen Sie Ihren Namen und die gewünschten Kontaktdaten ein.
  2. Passen Sie die Farben an und fügen Sie Ihr Logo hinzu.
  3. Scannen Sie die Vorschau, um den Kontakt zu prüfen.
  4. Als SVG für den Druck oder als PNG für digitale Nutzung laden.

Häufige Fragen

Ist das kostenlos? Laufen die Codes ab?

Ja, es ist kostenlos und ohne Anmeldung. Die hier erstellten Codes sind statisch: Der Inhalt steckt im Muster selbst, deshalb funktionieren sie dauerhaft und hängen nicht von unseren Servern ab.

Kann ich ein Logo und eigene Farben hinzufügen?

Ja. Laden Sie ein Logo als PNG, JPG, WebP oder SVG hoch, wählen Sie Farben oder einen Verlauf sowie den Stil von Punkten, Ecken und Rahmen. Das Logo wird in Ihrem Browser eingebettet und verlässt Ihr Gerät nie.

PNG oder SVG für den Druck?

Für den Druck ist SVG die richtige Wahl: Die Vektordatei bleibt in jeder Größe scharf, von der Visitenkarte bis zum Plakat. PNG (1024 px) eignet sich für Websites, Dokumente und soziale Medien.

Kann ich meine Daten nach dem Druck ändern?

Bei einer statischen vCard nicht, denn die Daten stecken im Code. Wenn sie sich oft ändern, erstellen Sie ein kostenloses Konto und nutzen einen dynamischen Code, der auf eine bearbeitbare Seite zeigt.
