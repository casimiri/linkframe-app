WLAN-QR-Code-Generator

Ein WLAN-QR-Code verbindet ein Handy mit einem einzigen Scan mit Ihrem Netzwerk – kein Buchstabieren des Passworts mehr. Legen Sie ihn auf die Tische Ihres Cafés, in die Ferienwohnung, in den Besprechungsraum oder an den Kühlschrank für Gäste.

Geben Sie den Netzwerknamen (SSID) genau so ein, wie er angezeigt wird, wählen Sie die Verschlüsselung und tippen Sie das Passwort ein. Die meisten Router nutzen WPA/WPA2/WPA3; „Keine (offen)“ nur für Netzwerke ohne Passwort wählen.

So erstellen Sie ihn

  1. Geben Sie Netzwerknamen und Passwort ein.
  2. Wählen Sie die Verschlüsselung und aktivieren Sie „Verstecktes Netzwerk“, falls das Netzwerk nicht sichtbar ist.
  3. Gestalten Sie den Code und fügen Sie einen Rahmen wie „Scannen für WLAN“ hinzu.
  4. Herunterladen, drucken und gut sichtbar aufstellen.

Häufige Fragen

Ist das kostenlos? Laufen die Codes ab?

Ja, es ist kostenlos und ohne Anmeldung. Die hier erstellten Codes sind statisch: Der Inhalt steckt im Muster selbst, deshalb funktionieren sie dauerhaft und hängen nicht von unseren Servern ab.

Kann ich ein Logo und eigene Farben hinzufügen?

Ja. Laden Sie ein Logo als PNG, JPG, WebP oder SVG hoch, wählen Sie Farben oder einen Verlauf sowie den Stil von Punkten, Ecken und Rahmen. Das Logo wird in Ihrem Browser eingebettet und verlässt Ihr Gerät nie.

PNG oder SVG für den Druck?

Für den Druck ist SVG die richtige Wahl: Die Vektordatei bleibt in jeder Größe scharf, von der Visitenkarte bis zum Plakat. PNG (1024 px) eignet sich für Websites, Dokumente und soziale Medien.

Wird mein WLAN-Passwort an Ihre Server gesendet?

Nein. Der Code wird in Ihrem Browser erstellt; nichts wird hochgeladen. Das Passwort steckt nur im QR-Code, den Sie herunterladen.
