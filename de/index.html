Kostenloser QR-Code-Generator

QR TekLid macht aus einem Link, einem WLAN, einer Visitenkarte, einer E-Mail, einer Telefonnummer oder einer SMS in Sekunden einen QR-Code. Wer ihn mit der Handykamera scannt, gelangt direkt zum Inhalt – ganz ohne zusätzliche App.

Alles passiert in Ihrem Browser: Inhalt eingeben, den Code mit Ihren Farben, einem Rahmen und Ihrem Logo gestalten und als PNG oder SVG herunterladen. Keine Anmeldung, kein Wasserzeichen und kein Ablaufdatum für die hier erstellten Codes.

So erstellen Sie ihn

  1. Wählen Sie den Inhalt: Link, Text, WLAN, Kontakt und mehr.
  2. Geben Sie die Daten ein – die Vorschau aktualisiert sich sofort.
  3. Wählen Sie bei Bedarf Farben, Rahmen und Punktstil und laden Sie Ihr Logo hoch.
  4. Laden Sie den Code als PNG für Bildschirme oder als SVG für den Druck herunter.

Häufige Fragen

Ist das kostenlos? Laufen die Codes ab?

Ja, es ist kostenlos und ohne Anmeldung. Die hier erstellten Codes sind statisch: Der Inhalt steckt im Muster selbst, deshalb funktionieren sie dauerhaft und hängen nicht von unseren Servern ab.

Kann ich ein Logo und eigene Farben hinzufügen?

Ja. Laden Sie ein Logo als PNG, JPG, WebP oder SVG hoch, wählen Sie Farben oder einen Verlauf sowie den Stil von Punkten, Ecken und Rahmen. Das Logo wird in Ihrem Browser eingebettet und verlässt Ihr Gerät nie.

PNG oder SVG für den Druck?

Für den Druck ist SVG die richtige Wahl: Die Vektordatei bleibt in jeder Größe scharf, von der Visitenkarte bis zum Plakat. PNG (1024 px) eignet sich für Websites, Dokumente und soziale Medien.

Kann ich das Ziel eines gedruckten Codes ändern?

Mit einem statischen Code nicht. Dafür brauchen Sie einen dynamischen Code, den Sie mit einem kostenlosen Konto (bis zu 2 gespeicherte Codes) jederzeit bearbeiten können – inklusive Scan-Statistiken.
