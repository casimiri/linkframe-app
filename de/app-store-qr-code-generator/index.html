QR-Code-Generator für App-Downloads

Ein App-Download-QR-Code ist ein einziger Code für alle Handys: iPhones landen auf Ihrer App-Store-Seite, Android-Geräte bei Google Play und Computer oder andere Geräte auf Ihrer Website. Sie drucken einen Code statt zwei, und niemand landet im falschen Store.

Da jeder Scan je nach Gerät weitergeleitet wird, ist dies ein smarter (dynamischer) Code, der ein kostenloses Konto braucht – mit bis zu 2 gespeicherten Codes und Scan-Statistiken. Der Generator unten erstellt ohne Anmeldung einen kostenlosen statischen Link-Code.

So erstellen Sie ihn

  1. Erstellen Sie ein kostenloses Konto und wählen Sie „Smarter App-Link“ als Ziel.
  2. Fügen Sie Ihren App-Store-Link, Ihren Google-Play-Link und eine Ausweich-Webseite ein.
  3. Gestalten Sie den Code und nutzen Sie Ihr App-Icon als Logo.
  4. Laden Sie ihn herunter und verfolgen Sie die Scans pro Gerät im Dashboard.

Häufige Fragen

Warum brauche ich ein Konto?

Die Weiterleitung nach Gerät passiert bei jedem Scan auf unserem Server, daher muss der Code in einem Konto gespeichert sein. Konten sind kostenlos und speichern bis zu 2 Codes.

Kann ich ein Logo und eigene Farben hinzufügen?

Ja. Laden Sie ein Logo als PNG, JPG, WebP oder SVG hoch, wählen Sie Farben oder einen Verlauf sowie den Stil von Punkten, Ecken und Rahmen. Das Logo wird in Ihrem Browser eingebettet und verlässt Ihr Gerät nie.

PNG oder SVG für den Druck?

Für den Druck ist SVG die richtige Wahl: Die Vektordatei bleibt in jeder Größe scharf, von der Visitenkarte bis zum Plakat. PNG (1024 px) eignet sich für Websites, Dokumente und soziale Medien.

Kann ich die Store-Links später ändern?

Ja. Smarte Codes sind dynamisch: Sie ändern die Ziele jederzeit im Dashboard, ohne den Code neu zu drucken.
