URL-QR-Code-Generator

Ein URL-QR-Code öffnet beim Scannen sofort eine Webseite. Auf Flyern, Verpackungen, Speisekarten, Schaufenstern oder Folien führt er Menschen zu Ihrer Website, einem Formular, einem Video oder einer Produktseite, ohne dass sie eine Adresse eintippen müssen.

Fügen Sie den vollständigen Link mit https:// ein, und der Code erscheint sofort. Halten Sie den Link möglichst kurz: Weniger Inhalt ergibt ein einfacheres Muster, das sich schneller scannen lässt – auch klein gedruckt oder aus der Entfernung.

So erstellen Sie ihn

  1. Fügen Sie die Webadresse ein, die geöffnet werden soll.
  2. Passen Sie Farben, Rahmen und Logo an Ihre Marke an.
  3. Scannen Sie die Vorschau mit dem Handy, um die Seite zu prüfen.
  4. Laden Sie den Code als PNG oder SVG herunter.

Häufige Fragen

Ist das kostenlos? Laufen die Codes ab?

Ja, es ist kostenlos und ohne Anmeldung. Die hier erstellten Codes sind statisch: Der Inhalt steckt im Muster selbst, deshalb funktionieren sie dauerhaft und hängen nicht von unseren Servern ab.

Kann ich ein Logo und eigene Farben hinzufügen?

Ja. Laden Sie ein Logo als PNG, JPG, WebP oder SVG hoch, wählen Sie Farben oder einen Verlauf sowie den Stil von Punkten, Ecken und Rahmen. Das Logo wird in Ihrem Browser eingebettet und verlässt Ihr Gerät nie.

PNG oder SVG für den Druck?

Für den Druck ist SVG die richtige Wahl: Die Vektordatei bleibt in jeder Größe scharf, von der Visitenkarte bis zum Plakat. PNG (1024 px) eignet sich für Websites, Dokumente und soziale Medien.

Muss der Link mit https:// beginnen?

Das wird dringend empfohlen. Handys erkennen eine vollständige Adresse mit https:// als Weblink und öffnen sie im Browser; ohne zeigen manche Scanner nur Text an.
