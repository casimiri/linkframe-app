Text-QR-Code-Generator

Ein Text-QR-Code speichert eine Nachricht direkt im Muster. Beim Scannen zeigt das Handy einfach den Text an – ohne Internetverbindung. Praktisch für Anleitungen, Seriennummern, kurze Notizen, Schnitzeljagden oder die Beschriftung von Geräten.

Da der Text im Code steckt, wird das Muster mit jedem Wort dichter. Beschränken Sie sich auf wenige Sätze für zuverlässiges Scannen und drucken Sie den Code größer, wenn die Nachricht länger ist.

So erstellen Sie ihn

  1. Geben Sie Ihre Nachricht ein oder fügen Sie sie ein.
  2. Gestalten Sie den Code mit Farben, Rahmen oder Logo.
  3. Scannen Sie die Vorschau, um den Text zu prüfen.
  4. Als PNG oder SVG herunterladen.

Häufige Fragen

Ist das kostenlos? Laufen die Codes ab?

Ja, es ist kostenlos und ohne Anmeldung. Die hier erstellten Codes sind statisch: Der Inhalt steckt im Muster selbst, deshalb funktionieren sie dauerhaft und hängen nicht von unseren Servern ab.

Kann ich ein Logo und eigene Farben hinzufügen?

Ja. Laden Sie ein Logo als PNG, JPG, WebP oder SVG hoch, wählen Sie Farben oder einen Verlauf sowie den Stil von Punkten, Ecken und Rahmen. Das Logo wird in Ihrem Browser eingebettet und verlässt Ihr Gerät nie.

PNG oder SVG für den Druck?

Für den Druck ist SVG die richtige Wahl: Die Vektordatei bleibt in jeder Größe scharf, von der Visitenkarte bis zum Plakat. PNG (1024 px) eignet sich für Websites, Dokumente und soziale Medien.

Wie viel Text passt in einen QR-Code?

Theoretisch einige tausend Zeichen, doch lange Texte erzeugen sehr dichte Codes, die schwer zu scannen sind. Am besten bleiben Sie unter etwa 300 Zeichen.
